# ampp-bpmn-epc-modeling
# Business Process Modeling – Appliance Repair Service

This repository contains a university project focused on the analysis and modeling of business processes in an appliance repair service.

## Project overview

The project covers key service processes related to:

* fault reporting
* service delivery
* spare parts procurement

The goal was to analyze the structure of these processes, identify the main participants and information flows, and represent the processes through formal models.

## Methods and tools

* BPMN
* EPC
* business process analysis

## Repository contents

* BPMN diagrams
* EPC diagrams
* project documentation
